# Core workflow

Cowlick uses one compact loop for AI-assisted engineering:

1. **Frame** — define the outcome, constraints, risks, and what is out of scope.
2. **Inspect** — read the affected system and reuse its established patterns.
3. **Choose** — select the smallest maintainable solution that meets the need.
4. **Execute** — let an appropriate person or AI tool perform the focused work.
5. **Verify** — test behavior, inspect the result, and challenge assumptions.
6. **Record** — capture decisions and usage guidance where future work finds it.

The loop is tool-independent. A human owns the outcome and makes the final call
when requirements, safety, or evidence conflict.
